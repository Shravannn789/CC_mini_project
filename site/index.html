Cloud Computing Mini Project

Split. Encrypt. Store.
Download from the cloud — safely.

Cloud Block Vault is a dependency-free Node.js tool that divides any file into fixed-size segments/blocks, encrypts every block with AES-256-GCM using a key derived from your passphrase (scrypt), and uploads them to object storage — Amazon S3 or a local store that mimics S3 semantics. Downloads pull the blocks back in encrypted form, authenticate them, decrypt and reassemble the original file byte-for-byte.

Read the docs Quickstart

What it does

Segmentation

Split files into blocks

Stream any file into fixed-size segments (default 4 MiB) with a per-block SHA-256 checksum — no matter how large the file is.

Encryption

AES-256-GCM per block

Each block gets a fresh random nonce and is authenticated with GCM. The key is derived from your passphrase with scrypt; blocks are bound to their vault and index.

Object storage

S3 without the SDK

Talks to the S3 REST API directly with Signature Version 4 signing implemented from the spec — verified against AWS's own published test vector.

Round trip

Download encrypted, restore later

Pull ciphertext exactly as stored in the cloud (--keep-encrypted), then decrypt it offline with restore once you have the passphrase.

Integrity

Verify end to end

Every block is checksummed in the manifest; GCM authentication catches tampering, and the reassembled file is verified against the original SHA-256.

Delivery

S3 + CloudFront site

Ships with a deploy script that publishes this site to a private S3 bucket behind CloudFront with HTTPS redirect and Origin Access Control.

Quickstart

# split a file into segments locally
node src/cli.js split video.mp4 --block-size 4m

# encrypt + upload (local store stands in for S3 by default)
export CBV_PASSPHRASE="your-strong-passphrase"
node src/cli.js upload video.mp4 --id video

# use real Amazon S3 instead
export AWS_ACCESS_KEY_ID=...  AWS_SECRET_ACCESS_KEY=...
node src/cli.js upload video.mp4 --backend s3 --bucket my-vault-bucket --region us-east-1

# download it back in encrypted form, then decrypt offline
node src/cli.js download video --keep-encrypted -o video.enc --backend s3 --bucket my-vault-bucket
node src/cli.js restore video.enc -o video-restored.mp4

Full command reference, architecture and the security model are in the documentation.
